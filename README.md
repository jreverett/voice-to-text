# Voice-to-Text

Local push-to-talk speech-to-text using whisper.cpp. Hold a hotkey, speak, release — transcribed text lands in your clipboard.

## Prerequisites

- Windows 10+
- [AutoHotkey v2](https://www.autohotkey.com/) installed

## Quick Start

```powershell
# 1. Clone and enter the directory
cd voice-to-text

# 2. Run setup (downloads ffmpeg, whisper.cpp, model, generates icons)
.\setup.ps1

# 3. Verify config.ini has the correct microphone name
# Use "List Audio Devices" from the tray menu if unsure

# 4. Launch
# Double-click voice-to-text.ahk, or:
autohotkey voice-to-text.ahk
```

## Usage

1. **Hold CapsLock** — recording starts (tray icon turns red)
2. **Speak** your text
3. **Release CapsLock** — transcription runs (icon turns yellow), then text is copied to clipboard (icon returns to green)
4. **Paste** anywhere with Ctrl+V

CapsLock's normal toggle behavior is suppressed while the script runs and restored on exit.

## Configuration

Edit `config.ini` to customize:

| Setting | Default | Notes |
|---------|---------|-------|
| `MicDevice` | Auto-detected | Exact DirectShow name from "List Audio Devices" |
| `PushToTalk` | `CapsLock` | Alternatives: `F13`, `ScrollLock`, `RAlt`, `F24` |
| `ExtraFlags` | `--no-timestamps --threads 4` | Passed to whisper-cli |
| `ModelPath` | `models\ggml-tiny.en.bin` | Swap for a larger model for better accuracy |

## Troubleshooting

**"ffmpeg.exe not found"** — Run `setup.ps1` first, or check that `bin\ffmpeg.exe` exists.

**Wrong microphone** — Right-click tray icon > "List Audio Devices". Copy the exact name into `config.ini`.

**"Too short" on every press** — Your mic may not be the default DirectShow device. Verify the device name in config.

**Transcription is slow** — The `tiny.en` model targets ~1s on modern CPUs. If slower, reduce `--threads` or check CPU load.

**CapsLock stuck** — The script restores CapsLock state on exit. If it crashes, press CapsLock once to toggle back.

## GPU Acceleration

For faster transcription with NVIDIA GPUs:

1. Download the CUDA/cuBLAS version of whisper.cpp from the [releases page](https://github.com/ggml-org/whisper.cpp/releases)
2. Replace the files in `bin\` with the CUDA build
3. Optionally upgrade to a larger model (`ggml-base.en.bin`, `ggml-small.en.bin`) for better accuracy

├── bin\                  # ffmpeg.exe, whisper-cli.exe (gitignored)
